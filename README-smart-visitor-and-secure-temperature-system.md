# Smart Visitor System and Secure Temperature Detector

An IoT-based academic project focused on developing a smart visitor management system and a secure temperature detection solution using embedded systems and electronic components.

## 📌 Project Overview

The **Smart Visitor System and Secure Temperature Detector** is an IoT-based project designed to combine visitor-related monitoring with temperature detection capabilities.

The project explores the use of embedded systems, sensors, and automation components to build a smart and security-oriented solution.

It was developed as an academic team project with a focus on practical implementation, hardware integration, and IoT-based system development.

## 🎯 Project Objectives

- Develop an IoT-based smart visitor system.
- Integrate sensor-based monitoring capabilities.
- Implement temperature detection using a temperature sensor.
- Explore hardware automation using a relay module.
- Build a practical solution using Arduino and ESP32.
